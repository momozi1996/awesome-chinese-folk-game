# 一键体验 Demo

```sh
python3 demo/run_demo.py
```

从本目录执行也可：`python3 run_demo.py`。Python 3.9+，无第三方运行依赖。

启动后浏览器打开 **http://127.0.0.1:4173/**。不开浏览器用 `--no-browser`；只检查文件用 `--check`。

- 首次体验：《借灯人》，从河灯求助帖读起。
- 连续故事：顶栏「案卷」→「寄名簿」→《灯灭之前》；后三夜随前案归档开放。
- 读帖 → 标记证据 → 私信 → 实地 → 手记配对 → 解释 → 报告 → 归档。
- 设置可导出当前案或整柜。退出窗口不会清除进度。
- Demo 使用完整的 9 案，不是只有首页的静态演示。58 个储备主题仅在 Markdown 库中，不伪装成可玩章节。

建议 16 岁以上体验，含死亡、失踪与心理压迫主题，无血腥图像或贴脸惊吓。声音默认关闭；所有解谜信息都有文字。
