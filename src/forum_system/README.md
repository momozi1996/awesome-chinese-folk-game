# Forum system / 未明旧案柜前端

这是原 `wanxiang-forum` 的前端实现，已纳入统一仓库 **awesome-chinese-folk-game**。

- [仓库主页](../../README.md)
- [启动说明](../../docs/install_guide.md)
- [玩法手册](../../docs/game_manual.md)
- [主题与可玩案卷库](../../cases/README.md)

从这里运行 `npm start` 会调用根目录 `main.py`。双击 `index.html` 也可离线游玩，需保留相邻的 `../case_engine/` 与 `../utils/`。

`data.js` 自动生成；不要手改。旧章节已迁至 `../../cases/`，`chapters/` 只留说明。`assets/` 是运行素材，与仓库顶层展示用 `assets/` 分开。V4 设计和测试历史保留；其中旧路径按 [迁移表](../../docs/repository_migration.md) 查找。
