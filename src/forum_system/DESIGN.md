# 《未明旧案柜》多案卷前端设计

设计及参考查阅日期：2026-09-18。

## 方向：论坛本身就是游戏场景

用户明确要求不使用 `huashu-design`。本次未调用该 skill，也没有套用网页审美模板。设计依据是原创剧情：一位夜班记录员在 2004 年的旧站上，追查一盏多出来的河灯，以及一位被错误记载的人。

不是把一个现代网站染黑，也不是为游戏制作营销落地页。功能的位置、状态变化和视觉物件应当解释「你在何处」「正在查什么」「发生了什么不对劲的事」。新增案卷共用终端骨架，但每一本有自己的地名、时间、现场图、人物和反转。

## 案卷结构

每个本子都遵循：

1. 民俗话语先给出一个看似完整的解释；
2. 论坛帖子留下现场疑点，但避免把传闻直接当事实；
3. 私信提供知情者与地点权限，调查者只能在可核对范围内取证；
4. 现场机关要求玩家重新排列时间、方向或仪式步骤；
5. 手记用五组证据关联拆开“鬼故事”；
6. 结案报告区分已证实、待核验和当事人隐私，再进入两种归档结局。

现有新增题材：

- 《空轿照夜》：冥婚古宅、女契与退帖，反转是被改写的女性退出记录与人为假声。
- 《铃过无名关》：湘西夜行传说、白签与封桥，反转是出山求助被倒写成赶尸归乡。
- 《年夜缺席》：东北守岁、饺子与座次、族谱裁页，反转是团圆习俗掩盖了一位选择离席的活人。
- 《最后一折》：江南阴戏、纸人、水路暗号，反转是旧案、复仇机关与新的名单窃取被混成一场摄魂戏。

## 借鉴与原创边界

借鉴的是媒介形式和节奏：在普通信息中发现异常，读帖与询问互相印证，再走出屏幕寻找物证。

以下全部使用本作自己的内容：

- 品牌「未明」、南湾旧城、夜班记录员、北窗、雨打芭蕉、陈渡与沈小禾。
- 六条水道的引路灯、第七盏空灯、被裁剪的报道和泵房事故。
- 以公开记忆与私人安慰区分的两种结局。
- 终端式画面构成、字标、纸船、场景插画、图标与声音。

不采用原作的姓名夺取设定、杂志社、人物背景、章节、台词或素材。「借灯」规则是虚构故事设定，不冒充真实民俗资料。

## 视觉与空间

- 底色 `#0b1217`，终端蓝绿 `#172329`，旧纸白 `#e2e0ce`，朱砂 `#c16c60`。不是直接沿用参考作品的配色与排版。
- 宋体用于故事与旧站文字，中文无衬线用于辅助操作，等宽数字用于文件与时间。
- 桌面：左侧是故事名、纸船河灯、剧情时刻和任务纸；中央是唯一的可滚动终端；底部是固定游戏操作。
- 手机：收起故事侧栏，保留终端、四个底部入口及设置。调查地点按画面重新定位热点，而非把桌面图片缩成不可点击的小图。
- 帖子正文集中呈现；手记是可以选择与关联的纸页，不是统计仪表盘。
- 没有宣传 Hero、产品卖点卡、付费按钮或虚构实时数据。论坛回应数属于静态剧情设定。

## 剧情驱动的界面反馈

1. 初始是正常旧站，第一项任务是阅读河灯帖。
2. 标记异常后，底栏显示「连接数 7 / 有效用户名 6」，帖子下出现注销账号的回执。
3. 从北窗获得地址，故事进入第二更，时刻来到 23:58。
4. 获得幸存者证言后，进入第三更，来到次日 00:16。
5. 结案后来到 06:02。时刻是章节节点，而不是倒计时，不会因阅读慢而失败。
6. 私信有短暂输入状态；等待期间可以切换视图。后台回复不得清空草稿、抢走输入焦点或解除弹窗隔离。

## 美术与声音来源

- `assets/town-night.jpg` 由 `assets/draw_scene.py` 从零程序绘制，绘制源文件随项目交付。未使用生图 API。
- 纸船、字印及界面图标由本项目 SVG/CSS 绘制。
- 磁带对白是原创文本，使用本地 macOS 中文语音合成，经过带通、回声、底噪处理，并加入七次合成敲击。完整文字转写可替代声音解谜。
- 环境雨声与低频声由 Web Audio 实时合成，默认关闭。
- 先前查阅过 Wikimedia、Unsplash 夜景候选，但未采用，不属于游戏资源。

## 有意限制

- 原有《借灯人》约 20–35 分钟；新增本子每本约 25–40 分钟。它们不是长篇商业游戏规模，但可以继续用同一数据结构扩展。
- 所有聊天与回复均为本地预设剧情；不连接 LLM 或真实用户。
- 无账号、后端、云存档或统计追踪。
- 自动保存调查状态；刷新回到论坛，不恢复当前阅读滚动位置。
- 为可读性保留明确操作标签；不通过隐藏必要按钮、突然闪屏或高音量制造恐怖。
