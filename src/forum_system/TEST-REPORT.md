## 本轮发现并修复

1. V3 的 `requires` 原来不影响帖子渲染，能提前阅读续帖。现在显示与点击处理均核查条件。
2. 原通用现场只按线索数量开放。V4 以 address 与推断条件开放，V3 仍保持原路线兼容。
3. 原新案“存档 / 交接信 / 玩法”仍描述首案。现按当前案卷生成，并支持单案/整柜导出。
4. 手机长热点标签互相挡住。现使用整幅不裁切画面、圆形热点以及图下同名按钮。重跑后通过。
5. 机关成功曾先标记“已取证”但尚未收录线索。现只在收录时更新取证计数。
6. 三种时间曾被同一种排序机关概括。现分别实现时刻核验、镜位对照、邮路复原与条款核验，补足各自现场对照材料。
