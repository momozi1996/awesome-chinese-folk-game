# V4《寄名簿》连续四夜（剧透）

从顶部「案卷」进入，先选《灯灭之前》。任一归档方式都开放下一夜；保留 V3 存档，无需先通关五宗旧案。

每案通用路线：
1. 读 opening / customs / archive / watch 四帖，分别标记 signal、custom、record、schedule。
2. 私信第一联系人，追问原档，取得 address。
3. 现场 A 收录 trace、register。
4. 手记配对 signal+trace、custom+register；选择有证据支持的结论。**必须完成这两条，才能开放复勘和更正帖。**
5. 回论坛读 dispute，标记 contradiction。
6. 现场 B 核验 sealed 谜题，打开后点击收录；再取 transfer。
7. 私信第二联系人，出示 sealed 与 contradiction，取得 witness。
8. 回论坛读 followup，标记 echo；coda 是可选人物尾声。
9. 完成剩余四组：record+schedule、sealed+witness、contradiction+echo、address+transfer。
10. 核对三项结案事实，选择公开核验或暂缓公开。可保留证据回看另一种归档，再交接下一夜。
