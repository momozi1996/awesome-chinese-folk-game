# V5 · 灯下旧档 / 视听打磨说明

这一轮只打磨 Demo 的视觉和声音，不新增本子，不改变九案剧情、证据 ID、坐标、门槛或结局。保留中式旧论坛与夜班档案终端，不使用 `huashu-design`，不引入参考游戏的美术或音频。

## 视觉

- 新增 `src/forum_system/immersion.css`：旧铜边框、褪色朱砂、纸纤维证据卡与布面案卷柜。旧版的固定导航、内部滚动和响应式规则保留。
- 标题栏与外部夜景随案卷变化；旧屋、阅读界面弱化雨幕，雪夜使用缓慢落雪，不在所有地点铺同一层天气。
- 十二处 Blender 现场重新输出为 **1920×1200**，增加木纹、墙面风化、反射与冷暖光。雪夜窗霜、戏帘褶皱与不同房间的色温分别处理；摄影机和核心物件位置不变，仍是预渲染现场，不声称实时 3D 或照片级画面。
- 场景只加轻微浮尘和暗角，切页有短暂渐入；无闪屏、随机人脸或贴脸惊吓。系统减少动态与游戏内开关均有效。
- 首案保留已经对应热点的原创夜景插画，避免为了换图破坏调查指向。所有线索仍可通过文字与同名按钮阅读。

## 声音

| 状态 | 听觉方向 |
|---|---|
| 论坛 | 隔窗细雨与轻微夜班电流 |
| 读帖 / 手记 / 旧案柜 | 远雨降低，为阅读留出空间 |
| 私信 | 更贴近室内的雨底，与短促消息提示 |
| 水岸 / 归乡驿站 | 檐下雨与稀疏水滴 |
| 井院 | 风声与错落水滴 |
| 旧屋 | 低声漏风 |
| 雪夜 | 去掉雨底，保留风声 |
| 空戏台 | 较空的穿堂风，不插入虚构唱词 |
| 归档 | 雨声渐远 |

合成声场随视图和地点过渡，不随机增加与剧情无关的讲话。翻页、查看物件、收录、消息到达与推断完成有轻量反馈。所有新增声音为本地程序合成；磁带保留原有素材与完整转写。

默认关闭环境与操作音；总音量 / 环境声 / 操作音独立调节，设为 0 不是仅隐藏图标，而是数字静音。点击磁带可独立试听；背景开启时播放对白会自动降低环境声。切到后台会暂停音频，不自动续播磁带。一个页面仅创建一个 AudioContext，切案或反复开关不会叠加声场。

## 存档与资源边界

原存档键名与 `version: 1` 不变，只为偏好增加 `ambience` 和 `effects` 两项，旧档缺少时使用默认值。重置当前案仍保留混音偏好，其他案件不受影响。

- 运行页面、纹理、场景、音效源码：`src/forum_system/`。
- 可重建美术源：`src/forum_system/art/source/`。
- 展示封面、真实截图、GIF：根目录 `assets/`。
- 旧版备份：`src/forum_system/backups/v4.1-before-immersion.zip`。
- 新发布包：`releases/awesome-chinese-folk-game-v5.0.zip`，保留 V4.1 历史包。

## 验证方式

`npm --prefix src/forum_system run test:all` 包含既有九案回归与新 `immersion-v5.cjs`：

- 默认不创建音频上下文；旧的开启偏好也需用户手势恢复。
- 三轨音量、静音输出、声音峰值、四个固定声源与短音回收。
- 实际页面/场景切换、磁带播放/退出/压低背景、保存/刷新/重置偏好。
- 减少动态、手机设置边界、无 Web Audio 时仍可阅读。
- HTTP 与 `file://` 本地资源、十二幅场景尺寸、无外部素材请求。

后台切换回调使用确定性的可见性事件模拟，验证 Web Audio 真正进入 suspended / running；不冒充手机真机测试。声音测试测量浏览器输出信号，不等于耳机声压或真人听感评估。实际听感请从默认低音量试起。

完整发布前另执行 Python 单元测试、共享引擎测试与解压包浏览器复验。原有迁移验收记录保留在 [V4.1 记录](validation.md)，不改写历史结果。
