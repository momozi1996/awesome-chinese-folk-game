## 重跑

```sh
python3 -m unittest discover -s tests -v
node tests/engine.cjs
# 先用另一个终端运行 python3 main.py --no-browser
npm --prefix src/forum_system run test:all
python3 tools/package_release.py
node tools/verify_package.cjs
```

Playwright 可通过前端目录 npm 安装，或 `PLAYWRIGHT_PATH` 指向已有模块。包验证临时解压在 `releases/.verify-*/` 并在结束后清理，使用端口 4187。原始浏览器日志保存在本地 `src/forum_system/tests/validation-migration.log`，不打进发布包。

## 保留的边界

58 篇是参考主题的结构化摘要与开发建议，不是成品。首案仍使用旧版专用 UI 适配，部分界面提示保留在 `app.js`；本轮只抽离共用门槛与状态逻辑，没有冒险重写已流畅的全部交互。
