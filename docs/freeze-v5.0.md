# V5.0 冻结检查 · 2026-09-18

**定位：本地 Demo 冻结基线；不是新增玩法版本，也不是已经取得全部授权的公开商业发行。**

统一根目录为 `awesome-chinese-folk-game/`。冻结包独立命名，不覆盖旧 V5、V4.1、V4、V3 等包；不重置玩家存档。本轮没有改剧情、证据 ID、谜题答案、解锁条件、现场热点或运行图片与声音。

## 检查范围

- `tools/audit_freeze.py` 递归清点**整个目录的每个普通文件**：相对路径、大小、SHA-256、用途分类、是否进入发布包、具体检查与发现。也记录本地研究、历史备份、日志与旧发布包；没有直接删除这些资料。
- 文本检查 UTF-8、JSON 重复键/语法、Python AST、JS / Shell 语法、SVG XML、当前 Markdown / HTML / CSS 的本地字面引用，以及冲突标记、常见凭据格式和个人目录路径。历史设计文档的旧路径按迁移说明保留。
- 所有图片逐帧解码，包括 GIF；音频用 ffprobe 与 ffmpeg 完整解码；全部 ZIP 逐成员 CRC、重复名、路径检查；Blender 工程校验压缩容器/文件头，现用工程另以禁用自动脚本的 Blender 打开检查。
- 9 案格式、线索引用、条件可达性、前后案交接与目录一致性；58 篇主题的唯一 ID、planned 状态及必需章节；连续四案创作源在临时目录重建比对，不覆盖正式剧情。
- 浏览器自动化使用独立临时上下文，覆盖九案通关、两种结局、错误反馈、响应式、导入导出、拒绝存储、声音混音及 file://。没有连接或清理用户日常浏览器档案。

**“逐文件检查”不表示逐字人工编辑所有剧情、逐成员执行历史包，或对安全、授权、所有浏览器作无限保证。** 历史 ZIP 检查完整性，但不运行其中程序；本次没有真人听感评测或手机真机验收。

## 冻结产物与复验

- `releases/awesome-chinese-folk-game-v5.0-freeze-20260918.zip`
- `releases/awesome-chinese-folk-game-v5.0-freeze-20260918.zip.sha256`
- ZIP 内 `awesome-chinese-folk-game/FREEZE-MANIFEST.json`：载荷每一文件的 SHA-256、大小与模式；不递归记录清单自身，清单由整包 SHA-256 保护。
- `releases/freeze-v5.0-20260918-inventory.json`：**本地工作目录**逐文件清单，含不发布的历史/日志/研究缓存。自身排除以避免循环；最终文件数和分类以 `summary` 为准。不要把整个工作目录直接当作发布物。

在项目根目录：

```sh
# 核对冻结 ZIP 是否改变（macOS / Linux）
(cd releases && shasum -a 256 -c awesome-chinese-folk-game-v5.0-freeze-20260918.zip.sha256)

# 解压、核对载荷、异地目录启动、HTTP + file:// 浏览器验收
# 需要可用 Playwright 与 Chrome，配置方式见安装指南
node tools/verify_package.cjs releases/awesome-chinese-folk-game-v5.0-freeze-20260918.zip

# 重新检查当前工作目录，不修改游戏数据；会更新本地清点报告
# 完整媒体检查另需开发工具 Pillow、ffmpeg/ffprobe、zstd、Node、zsh
python3 tools/audit_freeze.py
```

继续开发时用**新的文件名**打包，例如：

```sh
python3 tools/package_release.py --output releases/next-build.zip
```

相同环境、相同载荷可重复生成一致的 ZIP；不保证不同 Python/zlib 压缩版本必然产生相同的压缩字节，载荷散列可独立比较。文件系统未设置只读；请保留冻结 ZIP 和 SHA256，不把它作为后续编辑目录。没有擅自初始化 Git、建立 tag、提交或上传远程。
