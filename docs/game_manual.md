# 游戏手册（无核心谜底）

## 你在玩什么

「未明旧案柜」是一台虚构论坛的夜班终端。玩家是记录员，读到的帖子、回复和私信均为本地预设剧情，没有真人聊天，没有内容上传，也没有在线生成剧情。

九案中，前五案可独立体验；第六至第九案组成《寄名簿》。四夜不是四个任意拼贴的怪谈：每夜发现的交接材料会指向下一站，前案归档选择也会改变后案交接说明。

## 一次调查的完整循环

1. **读帖**：进入正文，辨别谁亲眼看到、谁在转述。帖子有预设追问；自由回复只留在本机，不会召唤真实聊天对象。
2. **标记证据**：阅读不等于已经收录。点击正文后的收录按钮，将证据加入「调查手记」。
3. **带着矛盾私信**：新问题受证据条件控制。找不到地址时，先读旧闻，再问相关人；不要只攒数量。
4. **现场取证**：取得许可或地址后，前往实地。点击画面热点或同名按钮；读完检查结果，还要收录。
5. **建立关联**：手记中选两份证据，点击建立关联。连续案还要求选出它们支持的解释。错误会提示缺口，不扣掉证据。
6. **回访与复勘**：正确推断解锁续帖、证人补充与第二处现场。它们不是一开始就能点的素材柜。
7. **核验谜题**：根据已经取得的记录处理时刻、镜位、邮路或授权关系，不需要掌握游戏外的玄学知识。
8. **报告与归档**：线索和脉络齐备后核对结案问题，选择公开或暂缓公开等记录方式。选择不改变已经查明的证据事实；完成后可回看和重选。

## 案卷与存档

- 顶部「案卷」切换故事，每案独立保存。
- 连续四案先完成上一案归档，下一案才开放。已经玩过的后续案不因切换或重置前案丢失。
- 自动存档使用浏览器 localStorage。存储不可用时仍可玩，但应及时导出。
- 设置 → **导出存档**：当前案；**导出整柜**：所有案卷和当前选中案。
- 导入前会检查格式并确认。旧 V1 首案、V3 单案和 V4 整柜均有兼容路径。
- 「重新开始」只重置当前案。先导出备份，再做任何重置。

## 卡住了怎么办

先看当前任务或「接着调查」。手记上未发现的证据有寻找提示。确认是否只阅读但未标记、是否尚未点击对话选项、是否还有一条关联没有提交解释。没有必要反复点击锁住的场景，也无需等待现实中的半夜。

## 无障碍与声音

Tab 移动焦点，Enter/Space 操作按钮，Esc 关闭弹窗。小屏可通过现场下方按钮调查热点。设置可关闭动态效果与声音；磁带等音频均有文字转录，没有必须听出来的密码。

### V5 声音与动态设置

- 顶栏 **声音关 / 声音开**：启停环境声与操作音效。首次进入默认关闭；记住的开启偏好也要等你点击或按键后才恢复，不会绕过浏览器自动播放限制。
- **存档 / 设置 → 总音量**：同时控制环境声、操作音和磁带。设为 0 时全部静音。
- **环境声**：单独调节雨、风、水滴与夜班电流。进入不同现场时自动过渡，无需手动选择曲目。
- **操作音**：单独调节翻页、线索收录、私信到达与推断完成的反馈。可用「试听纸页」试音；它不会推进剧情。
- **磁带**：只有主动点「播放残留录音」才播放，即使环境音关闭也可独立试听。环境音开启时，播放磁带会自动压低背景；关闭磁带弹窗、关闭声音或离开标签页会停止/暂停。回到标签页不会自动续播对白。
- **动态效果**：关闭雨幕、浮尘与切页动画；也遵循系统的减少动态设置。没有闪屏惊吓。
- 建议先从默认总音量 30%、环境声 55%、操作音 65% 开始，再按设备调节。请不要为了寻找不存在的音频线索而把耳机开到很大；关声音同样能完成全部案件。

三个音量与动态偏好自动保存在当前浏览器，重置案件不会重置混音偏好。切换案卷不会叠加多套背景音。

## 内容边界

参考主题不是成品，不会在游戏中显示 58 个假入口。所有人物和规则为虚构；不代表真实民俗或现实调查方法。不模仿夜探、涉水、攀爬、接触电路等行为。可玩内容建议 16+；主题库另含儿童受害、性别压迫和私刑等较沉重方向，阅读反转前请自行判断。
