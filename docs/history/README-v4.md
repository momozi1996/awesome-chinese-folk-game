# 未明旧案柜 · V4「寄名簿」

原创中式民俗悬疑论坛游戏。**五宗独立旧案 + 四夜连续故事**，不是游戏宣传页。延续 V3 的夜班终端、读帖、私信、实地取证与手记风格，未使用 `huashu-design`。

## 开始游玩

- 双击 `index.html`，或 macOS 双击 `启动游戏.command`。无需安装，断网可玩。
- 本地服务：在本目录执行 `python3 -m http.server 4173` 或 `npm start`，访问 **http://localhost:4173/?v=4**。
- 顶部 **「案卷」→「寄名簿」→《灯灭之前》** 开始新篇。不会清除 V3 进度。
- 桌面和手机均可操作。Tab 导航、Esc 关闭弹窗；声音默认关闭，所有关键音频信息均有文字。

## 这次不是把题材堆成列表

| 夜晚 | 案卷 | 取材与核心推理 |
|---|---|---|
| 一 | 006《灯灭之前》 | 命灯、隔墙听声、守夜旧账；分开原帖、附件、求助与死亡的时间 |
| 二 | 007《镜中无籍》 | 寄名、古镜、旧衣；通过镜位实验分开视觉假象与身份认定 |
| 三 | 008《井底回邮》 | 封井、字纸引魂、镇石；复原一封信真正经过的中转路线 |
| 四 | 009《归宗空席》 | 归宗、瓦匣传说、层叠封存；核查更正记录是否夹带代签授权 |

每夜是前夜未解线索的下一站。**每夜 8 篇帖子、12 份证据、6 条需判断的关联、2 处现场、1 个核验谜题、2 种归档方向**。合计新增 32 篇帖子、48 份证据、24 条推理、8 处现场、8 个章节结局。

- 续帖、证人补充、复勘地点受证据和推断条件控制，不提前泄露反转。
- 选两份证据后，还要判断它们到底支持什么；误判给出依据提示，不扣线索。
- 四种现场核验分别处理时间、镜位、邮路、授权，不再全部套同一种顺序锁。
- “接着调查”指向当前可行动的帖子、联系人、物件或手记，不靠盲点推进。
- 前案公开/暂缓公开的选择保存在存档中，改变下一夜交接说明。两条路都能继续调查，不用隐瞒造假换取“好结局”。
- 最终查明的是身份记录的改写与循环认证链。相关死亡、失踪的未决责任会明确保留，不虚构一个证据不足却包办一切的最终凶手。

阅读时长仅为估计：每个新案约 **35–50 分钟**，依阅读与推理速度而异；未经过真人时长标定。并未把用户提供的 30 个主题全部做成独立可玩本，选材与未采用原因见 `STORY-BIBLE-V4.md`。

## 美术

- **12 幅原创三维预渲染现场，1536×960**：新篇 8 幅，V3 四案各 1 幅。
- 木构、石地、旧镜、夹衣、灯台、井沿、纸件和档案柜均由本项目建模/程序材质生成，无外部模型、贴图库、参考游戏截图或网络素材依赖。
- 不是 AI 生图：使用 Blender / Cycles 本地渲染，源代码及最后一个场景工程在 `art/source/`，说明见 `art/README.md`。
- 手机保留整幅画面的坐标，不裁切关键区域；热点下方提供同名按钮，避免小屏标签互相遮挡。

## 存档与兼容

- 原《借灯人》仍使用 `weiming-lantern-save-v1`，V3 四案仍使用各自的 `weiming-case-<id>-v1`。
- 新案同样按案保存；当前案卷使用 `weiming-active-case`。
- **设置 → 导出存档**：当前案卷；**导出整柜**：九案与当前案卷一起备份。
- 导入支持原首案 JSON、带案卷标识的单案 JSON 和 V4 整柜 JSON。确认前不替换，未知案卷或损坏格式不会直接写入。
- **重新开始只重置当前案卷**，不会清空其他故事。已玩过的后续案仍可继续。
- 存档在浏览器，不在游戏文件中。不同浏览器、端口、`file://` 与 `http://` 不共享存档；迁移请导出/导入。浏览器禁止存储时请及时导出。

## 开发与验证

游戏无运行时依赖、不需要构建。浏览器测试需要 Node.js 与 Playwright：

```sh
npm install
npm start
# 另一个终端
npm run test:all
```

默认使用 macOS Chrome；可通过 `CHROME_PATH` 指定，也可 `npx playwright install chromium`。`GAME_URL` 默认 4173，`PLAYWRIGHT_PATH` 可复用已有模块。

`test:all` 包括：数据完整性/依赖图、原案完整流程、原版响应式、交互回归、V3 四案流程、V4 连续四案全流程。V4 测试包括错误推断、错误谜题、反转门槛、双结局、整柜和单案存档、重置隔离、64 个响应式视图与离线资产。详见 `TEST-REPORT.md`。

## 内容与原创边界

所有人物、地点、事件、寄名及命灯等规则都是**原创虚构**，不代表真实地区、民族或宗教习俗。没有使用《頭七》的角色、台词、品牌、美术或剧情。题材包含死亡、失踪、恐吓与身份剥夺，建议 16 岁以上体验；无血腥图片、无突发贴脸惊吓。不要模仿夜探废墟、涉水、攀爬、接触电路等危险行为。
