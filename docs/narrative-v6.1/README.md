# V6.1 Preview · 灯影之间，有人读起旧帖

本轮在 V6 上**实际实现**夜读演出与原文旁读，不重写游戏、不改案件或谜题。修改前备份：`src/forum_system/backups/v6-before-narrative-v6.1.zip`，不进入发布包；V6.0 发布包不覆盖。

## 设计合同

继承 V6 的夜班终端、分场景声场、双证据工作台、预渲染现场及可选 Three.js 灯台查看。本轮新增的是帖子阅读的 SVG/CSS 叙事演出、13 段本地语音和相应交互控制。**不做随机惊吓、伪造现场录音、全篇配音、自动获取线索或新 3D 谜题。**

### 演出不是素材随机轮播

| 意象 | 实际画面/运动 | 触发来源 |
|---|---|---|
| 灯笼 | 纸面透光、竹骨、穗线、一次缓摆及水纹 | 《借灯人》河灯帖、《铃过无名关》首帖 |
| 信件 | 旧纸升起、信封展开、抽象墨迹与封印 | 旧报纸、被挤掉的一行、井底回邮、空席、红纸等对应帖 |
| 六灯 | 六个铜托电珠、共同电线；微恐模式缓慢熄暗再恢复 | 《灯灭之前》首帖；非六根蜡烛，不误导电路证据 |
| 镜影 | 旧镜反射中极淡的轮廓，微恐模式轻微漂移 | 《镜中无籍》首帖 |
| 烛火 | 烛泪、托盘、暖光、两次有限的火焰呼吸 | 《年夜缺席》首帖 |
| 幕影 | 戏台帷幕、纸偶剪影和细长操纵杆，缓慢小幅转动 | 《最后一折》首帖 |

图像被标为“阅读意象”，字幕是当前帖子的已有原文；不引入伪线索。实际可播放清单包含 **11 段帖子 + 2 份已获取线索**。线索旁读不自动演出，只有收录后在证据对照/查看处出现。

### 节奏与控制

- 默认 **轻柔 / 自动演出开 / 声音关 / 自动旁读关**。
- 进入指定帖子后等待 1 秒；不在输入中、弹窗内、后台或另有旁读时出现。
- 同一片段的自动演出只出现一次；跨片段冷却 90 秒；当前打开周期最多 3 段。记录保存在独立展示设置里，不改案卷进度。
- 自动片段持续 5.2 秒，不占用键盘焦点。手动回看不倒计时，可慢慢阅读；自动结束后原文仍完整留在帖子和节选文字中。
- 550ms 入场，灯摆/展信/缓暗等各自采用一次或有限次动画；180ms 收起。点击导航、继续操作或滚动阅读可取消片段，不让装饰拦住调查。
- 「收起/跳过」与 Escape 可随时退出；支持键盘焦点返回和片段内控制循环。系统“减少动态”优先：无自动演出，手动回看静态。
- 轻柔、微恐、关闭三档。微恐是缓慢压暗与淡影，**无频闪、贴脸、尖叫或晃动正文**。

### 旁读与混音

- 不是实时调用 TTS 服务：13 个 MP3 随游戏提供，无需联网、API Key 或麦克风。仅主动播放时创建/加载 Audio。
- 原文全文字幕 + 实际进度；暂停/续播、重播、停止、0.85–1.15× 语速；旁读音量与总音量相乘。
- 演出打开时，播放器嵌在片段底部，使用上方原文作字幕；收起演出后，播放器移到阅读页角落，继续显示完整字幕。线索弹窗拥有自己的播放器，不与焦点隔离冲突。
- 旁读开始时压低环境声，暂停/停止/失败后恢复。与原有磁带互斥，不叠两个讲话声；空闲旁读模块不会错误解除磁带的环境压低。
- 切页、切案、打开其他游戏弹窗、关闭声音、总/旁读音量归零、进入后台时停止；回来不自动续播。
- 音频缺失或播放被拒绝时提供明确状态及重试，不删除原文，不影响取证。

## 快速体验

当前开发地址：`http://127.0.0.1:4176/`。没有运行服务时，从项目根目录执行：

```sh
python3 main.py --port 4176 --no-browser
```

1. 《借灯人》→ 河灯求助帖，停留约 1 秒，看灯影浮现。
2. 在片段或正文工具条点击「开启声音并朗读」。
3. 「存档 / 设置」→「夜读演出与旁读」切到微恐；可选打开自动旁读。
4. 「案卷」→《灯灭之前》→ 首帖，查看六灯缓暗；读过的片段用「重看片段」。
5. 后续案件仍按原有归档解锁顺序开放，不为看动画绕过门槛。

**继续旧档请使用原浏览器、主机名、端口。** 不要为再次触发演出清除案卷存档。直接双击 `src/forum_system/index.html` 也可播放本地旁读；V6 的可选 3D 仍建议通过本地启动器体验。

## 工程与素材

- `presentation/narrative.js`：展示状态、触发冷却、片段、焦点、本地音频生命周期。
- `presentation/narrative-art.js` / `narrative.css`：六套原创 SVG 与有限动画、桌面/手机布局。
- `presentation/readings.js`：从规范案卷生成的节选清单；不是新的剧情状态源。
- `assets/voice-v6/`：13 段 MP3。
- `art/source/narrative/build_readings.py` / `readings-manifest.json`：重建脚本、原文案卷/段落、音色、时长与 SHA-256。
- `tests/narrative-v6.cjs`：新增专项回归；已加入 `npm run test:all`。

TTS 重建需要 macOS 系统 `say`、所用系统音色、FFmpeg/ffprobe；运行游戏不需要。音色为 Tingting 与 Eddy（中文中国大陆），均是合成旁读，不是演员或现场录音。高低切、-22 LUFS 归一化、轻柔起音处理不代表已做专业听感制作。

**语音再分发/商用授权未核验，正式公开发行前须核实或替换为已授权音源。** 本轮只做本地预览，没有上传、部署或代第三方授权。完整来源与边界见根目录 `NOTICE.md`。
