## 人工图像检查

实际打开检查了新点验厅 / 走廊 / 灯台近景，以及桌面论坛、现场、3D 弹窗、证据对照和手机页面截图。根据首轮检查修正了：

1. 场景光照过平：调整冷暖光、明暗重心与前景构图，补充桌面磨损和环境细节。
2. 子目录样式中相对纹理 URL 解析错误：改用本地绝对资源 URL，完整回归无 404。
3. 现场图片下沿被内容窗遮住：按视口高度重新约束完整摄影画面。
4. 热点圆点装饰脱离自身定位：恢复定位包含块，移动端保持 44px 触区但不遮挡物件。
5. 3D 弹窗受旧 max-width 限制：桌面采用真正宽幅的图物 / 原文双栏；手机依然纵向阅读。
